# Sales Forecasting Dashboard

This is an interactive analytics dashboard integrating Prophet and ARIMA time series models with live simulated SQL data feeds to assist in critical executive business decisions.

## Project Architecture
* **src/model.py:** Formulates the time-series mathematical trends combining cyclical noise and auto-regressive error metrics.
* **src/app.py:** Serves interactive multi-metric charts mimicking high-fidelity enterprise data dashboards.

## Running the Code
1. Run setup command: `pip install -r requirements.txt`
2. Start server terminal: `streamlit run src/app.py`

## Tech Stack
* Python, Streamlit, Plotly Express, Pandas, NumPy (Conceptual Reference: Power BI / SQL workflows).
